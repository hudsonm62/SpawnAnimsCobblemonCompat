# SpawnAnimations Cobblemon Extension

Basic support for Cobblemon in [SpawnAnimations](https://modrinth.com/project/zrzYrlm0).

> Due to Cobblemon's Spawning mechanics, you may need to increase the Activation Distance to 40 or higher blocks to prevent Pokemon from bugging out in the distance.
> Also, the "Vanilla" activation mode currently does not work at all.
